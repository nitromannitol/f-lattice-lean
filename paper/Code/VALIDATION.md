# Validation

## Corrected edition

The corrected edition passed 433 assertions on both Julia 1.7.1 and Julia 1.12.5. The exact period routine additionally checked all 484 standard and alternate outputs through depth four. This includes agreement on every repeated native height and a binary Laplacian over each entire period. Direct regressions exercise the old 37-two and 44-two failures. [Results](test/results/corrected-edition.txt) · [Regression source](test/pattern_test.jl)

## Earlier reference-package validation

The original reference-package results below used Julia 1.10.13, Linux x86_64. No third-party Julia packages or plotting libraries are used.

1. **Actual original Julia comparison.** `test/compare_original.jl /path/to/final_code` runs the original numerical constructor and the exact reference independently, reanchors each output by its actual lexicographic LL, and compares exact dictionaries. It does **not** subtract height offsets. All 8 registers for each of 17 words matched: **136 arrays, 31,404 occupied site-height entries**. Words: empty, 1, 2, 3, 11, 12, 13, 21, 22, 23, 31, 32, 33, 113, 123, 232, 323. No claim about untested words comes from this comparison.
2. **Original reference-package regression suite.** `julia --project=. test/runtests.jl` passed 297 assertions: true integer translations/touch preconditions; all **31 archived original Julia TSVs** exactly in support and raw values; word validation, saved-role and true birth selection. The fixture files and their SHA256 checksums are under `test/fixtures`. Reference tile data must not be silently regenerated from the code being tested.
3. **Independent final public-interface check.** A separate original Julia run exported all eight registers for 12 words, including 121 and 131. The final sparse API's written rows matched **byte for byte**, after stripping its header: 96 register exports and 26,298 native entries. This overlaps the 17-word test; these are not disjoint or independent counts.
4. **Offset verification.** Optional `test/offsets_test.jl` compares the original Julia rational/offset tables and tests beyond machine precision: **15,346 assertions passed**. It includes every word through length five, all standard/alternate tables, both flips, and inverse history beyond 999 steps. Initializer differential tests additionally compared every entry of all eight original source-port registers for empty and pure runs of lengths 1–8.
5. **Clipping stress.** For an actual consumed helper, save ancestor word 1, let the current prefix be 1 followed by k copies of 2, then take next digit 2. Test the odd flipped LONG helper for the corrected odd alternate. At k=77 the original and sparse supports both have 3,766 sites; at k=78 the original returns **3,799** against **3,814** in the sparse replay. All common entries have identical heights, so these 15 missing sites are specifically a canvas defect. At k=200 the original helper gives a BoundsError, whereas the exact helper has **9,670** sites. `julia --project=. test/clipping_demo.jl /path/to/final_code` verifies the exact helper against an independently coded full-support ordered-minimum replay, the 15-site fixed-canvas loss, and that the emulated fixed canvas loses a required overlap at k=200. The original dense k=200 call was a separate direct execution, not the sparse emulation. A huge-coordinate unit case also checks exact placement far beyond both the original canvas and Int64. These are **helper** regressions, not by themselves a claim that a whole k=200 output was built.

Raw text results are in `test/results`. The optional old-source comparisons need the original `final_code` checkout; the ordinary package and shipped regression suite do not. Testing exercises both correction orientations and both alternate types; it is not a general mathematical recurrence test or a proof of absolute absence of programming errors.
